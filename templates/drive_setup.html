  1. Set STORAGE_ADMIN_EMAIL in Vercel to the Google account that should own stored files.
  2. Sign in to QuickShare with that same account, then click Connect Google Drive above.
  3. Copy the refresh token shown after consent and add it to Vercel as GOOGLE_DRIVE_REFRESH_TOKEN. Set GOOGLE_DRIVE_REDIRECT_URI to the same callback URL shown above. Keep GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET configured too.
  4. Redeploy so Google Drive becomes available in the upload form.
Privacy note

The file contents are private in Drive when the Google Drive option is selected. Share metadata—including original filename, expiry, download counts, and an account-owner hash—continues to be stored in the public GitHub repository. Avoid sensitive filenames. Google OAuth apps left in Testing mode can issue refresh tokens that expire after seven days for scopes beyond basic sign-in.
